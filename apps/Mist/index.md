# Mist <img src="https://cdn.jsdelivr.net/gh/selfhst/icons/svg/apple-retro.svg" alt="macOS" width="20">

![Mist](intranet/_assets/attachments/downloads_mist.avif)

**GitHub:** [ninxsoft/Mist](https://github.com/ninxsoft/Mist/)
**Developer:** ninxsoft

A Mac utility for listing, downloading, and creating bootable installers for all available macOS firmware versions and installers.

## Key Features

- Display comprehensive details: names, versions, builds, release dates, and file sizes
- Optional display of beta/pre-release macOS versions
- Filter versions by compatibility with the current Mac
- Export lists in multiple formats: CSV, JSON, Property List (plist), or YAML
- Direct download of macOS installers and firmware
- Automatic verification of downloads
- Create bootable installers on external drives
