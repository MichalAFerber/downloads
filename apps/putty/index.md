A free and open-source terminal emulator, serial console, and network file transfer application. Supports multiple network protocols including SSH, Telnet, SCP, rlogin, and raw socket connections.

## Suite Tools

| Tool | Purpose |
|---|---|
| **PuTTY** | Terminal emulator |
| **PSCP** | SCP client |
| **PSFTP** | SFTP client |
| **PuTTYgen** | Key generator |
| **Pageant** | SSH authentication agent |
| **Plink** | Command-line connection tool |
