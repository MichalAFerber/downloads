# Latest <img src="https://cdn.jsdelivr.net/gh/selfhst/icons/svg/apple-retro.svg" alt="macOS" width="20">

![Latest](intranet/_assets/attachments/downloads_latest.avif)

**Website:** [max.codes/latest](https://max.codes/latest/)
**Developer:** Max Langer

A free and open-source application for macOS that monitors and checks if your installed apps are up to date. Provides a quick overview of available updates with changelogs and allows one-click updates.

Currently supports apps from the Mac App Store and applications that use the Sparkle update framework, covering the majority of macOS applications. Features include automatic update checking, detailed release notes, and direct update installation.
